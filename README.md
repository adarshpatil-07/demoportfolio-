# Demo Portfolio

A single-page developer portfolio built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## Features

- Hero home page with links to every section
- Sections: Projects, Skills, Open Source, Experience, Contact
- Hash-based navigation (`#projects`, `#contact`, etc.)
- Responsive layout
- Automatic dark mode

## Structure
# Project Structure

```
demoportfolio/
├── index.html   # all sections
├── style.css    # all styles
├── script.js    # hash router
├── README.md    # project info

```


## Run locally

Clone the repo and open `index.html` in your browser.

## Deploy

Works on any static host (GitHub Pages, Vercel, Netlify).
